## Daily ritual

Do **one** of these each day. Either one counts toward your streak.

1. **Plant**: run `npm run new "Your title"` (or add a markdown file in `src/content/notes/`) and write a few lines.
2. **Tend**: open an old note, add a link, sharpen a sentence, and bump the `updated` date. If it has grown, promote its status.

## From your phone

Open this repo in the GitHub app, add a file under `src/content/notes/`, and commit. The site rebuilds itself. Or sync the folder with Obsidian.

## Growth stages

- 🌱 **Seedling**: a rough idea, probably wrong in places.
- 🌿 **Budding**: has structure and a few links.
- 🌳 **Evergreen**: you'd stand behind it.
